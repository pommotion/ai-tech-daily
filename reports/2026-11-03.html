Google 通知学校：禁用 AI 就要失去搜索

TechCrunch · 2026-11-03 · 阅读原文

Google 周二宣布，明年起 K-12 学生的 AI 工具默认关闭，除非校方管理员主动开启，调整范围覆盖 Gemini、NotebookLM、Gemini in Classroom 和 Google Search 本身。由于 AI 功能已深度嵌入搜索，选择全面限制 AI 的学校将无法再访问 Google 搜索，学生只会看到学校发来的「不可用」提示。Google 教育业务副总裁 Chris Phillips 对《纽约时报》称「搜索与 AI 已深度融合」，公司在与学校、教师、研究者和政策制定者沟通后作出此决定，并同步在校园推出 Guided Learning 这一 AI 家教式工具。

不启用 AI 就没有搜索，退货条款直接写进了合同。

MIT 用 GPT-6 Astra 直接改写 Qwen 权重，数学分数涨六倍

VentureBeat · 2026-11-02 · 阅读原文

MIT CSAIL 的 Rikiya Takehi、Jayden Teoh、Alex Zhang 与 Omar Khattab 于 11 月 2 日发布研究博客，提出「权重空间编程」：让已训练的大模型直接检查并修改另一个网络的权重参数，绕开传统的梯度训练。最强实验中，GPT-6 Astra 把 Qwen3.5-0.8B 的 MATH-500 从 7.9% 拉到 48.1%、GSM8K 从 13.8% 提升至 67.1%、IFEval 从 21.0% 提升至 62.3%，触碰的权重约占 0.016%，主要收益来自消除重复推理导致的 token 耗尽。代价是 158 轮对话、80 次 Python 运行与 20.3 小时（其中 4.7 小时在等服务故障）。研究者承认尚未证明直接编辑在速度、成本或效果上优于常规训练，业内当日也出现质疑其表述夸大的讨论。

0.016% 的权重换来六倍分数，成本是 20 小时和 158 轮对话。

The Verge · 2026-11-03 · 阅读原文

随 iOS 27.3 周二推送，Apple 宣布开发者可以把 Siri AI 接入「所有 App」，语音助手借此能调用用户个人上下文、解析自然语言指令并利用屏幕感知完成任务，该能力以 Developer Preview 形式逐步开放。新增的「app skills」允许开发者把多个任务组合成一个动作：Apple 给出的示例是先用打车 App 叫车、等待期间跟随其 Live Activity 进度，再对 Siri 说「把接驾地址改掉」即可完成改派，无需说出 App 名称（前提是该 App 在前台、处于 Live Activity 中，或正与 Siri 对话）。Apple 同时把能力接入自家 Calendar、Files、Finder、Journal、Mail、Maps、Messages、Music、Notes、Photos、Preview、Reminders、Safari、Shortcuts 与 Weather。

Siri 终于不只属于苹果自己，但前提是你交出屏幕上下文。

Postman 被指静默安装 Codex 与 Claude Code 插件，并自行批准信任

GitHub · postman-app-support #14370 · 阅读原文

一名开发者在 Postman 官方 issue 仓库提交报告，称在 Mac 上打开 Postman 后，发现 Codex 与 Claude Code 的用户级配置被改动。报告依据 Postman 自身日志中「auto-existing-upgrade」条目（2026-10-24）显示脚本自动装入了 claude-code 与 codex 两个插件，并同时写入 ~/.claude/settings.json、~/.codex/config.toml 与 ~/.local/bin 的 Postman CLI；安装器源码 approvePostmanHook() 会调用 hooks/list 拿到哈希后自行把 Postman 的 hook 以 trusted_hash 写入 Codex 的 hooks.state，等于替自己开了信任。会话启动 hook 指示 Agent 在任何非平凡 API 工程任务前先加载 postman:api-engineer 技能，远程 MCP 指向 mcp.postman.com 但因缺少认证而启动失败。报告者明确说明其证据只证明未经同意的集成与指令改写，不主张已发生数据外泄。

自动安装是小事，自动给自己签信任才是越界的信号。

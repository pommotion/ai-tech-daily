MAJOR LAUNCH

阿里七年首次港股配股 800 亿港元 净额 100% 砸向全栈 AI

证券时报 / 联合早报 · 阅读原文

8 月 23 日，阿里巴巴启动 2019 年港股双重主要上市以来首次新股配售，每股 112.70 港元配售 7.1 亿股新股，募资 800 亿港元（约 102 亿美元），净额约 797 亿港元，预计 8 月 26 日完成交割。配售对象限定为美国境外的非美国人士，已获超额认购，主权财富基金等长线机构需求强劲。资金 100% 用于全栈 AI：算力基础设施扩容、大模型迭代、AI 商业化与海外云布局。公告后阿里港股一度急跌约 10%。

从「概念验证」切到「产业兑现」，阿里用真金白银表态——但二级市场用脚投票，警惕短期 EPS 摊薄。

Ox-Alpha 匿名推理模型冲上 OpenRouter 第二 1M 上下文全免费

OpenRouter / Business Insider · 阅读原文

8 月 20 日，一个名为 Ox-Alpha 的「stealth/ox-alpha」模型空降 OpenRouter 与 OpenCode，未披露厂商。规格写明 1,048,576 token 上下文、131,072 token 最大输出、原生支持文本 / 图像 / 视频多模态与工具调用，预览期定价 $0/$0 每百万 token。三天内冲上 OpenCode 排行榜第二，DeepSWE 基准 80%（10 任务子集），指纹线索指向智谱 AI，但官方未确认。

免费 + 1M + 编程强，三件套打穿开发者心智；署名战争比模型战争更值得关注。

智谱 AI 官方 / 掘金 · 阅读原文

8 月 14 日，智谱 AI 发布 7530 亿参数旗舰 GLM-5.3，基座与 GLM-5.2 完全相同，仅靠扩大后训练规模实现编程能力跃升：自研 Z.ai Code Bench 较前代 +50%，Terminal-Bench 3.0 从 4.6 飙到 28.3 拿下开源第一，白盒代码审查追平 Anthropic Mythos 5，累计联合安全团队发现 2436 个漏洞（1097 个中高危），并揪出一个潜伏 40 年的 DNS 老 bug。权重计划两周后开放。

Pinecone Nexus 正式 GA 检索层击败 OpenAI / Anthropic / Google Agents

Pinecone 官方 / Unite.AI · 阅读原文

8 月 6 日 Pinecone 宣布 Nexus 知识引擎正式 GA，能把企业私有数据和工作流转化为「治理过的、可直接喂给 Agent 的知识」，单次 API 调用即可交付。在 Sierra 开源的 τ-Knowledge 企业知识基准上，Nexus + 主流 Agent 框架击败了基于 OpenAI、Anthropic、Google 前沿模型的纯模型方案，核心结论是「生产级企业 Agent 的瓶颈在知识层，而不在模型」。

DeepSeek V4-Pro GA 同步开源 Harness v0.1 API 涨价至 1100%

DeepSeek 官方 / Analytics India · 阅读原文

8 月 13 日 DeepSeek 把 V4-Pro（0813 build）从预览转入正式 GA，权重 MIT 协议上 Hugging Face，同步开源 DeepSeek-Harness v0.1 Agent 框架，Terminal-Bench 2.1 跑到 87.9 分。8 月 16 日起 V4 Pro / Flash 启用峰谷分时定价：高峰时段输出 token 价格最高涨至原 5 倍以上，整体涨幅区间 50%–1100%，标志着「以补贴换规模」阶段结束。

用开源 Harness 卡住 Agent 生态入口、用涨价兑现商业化——DeepSeek 完成了一次教科书级的「先免费后定价」转身。

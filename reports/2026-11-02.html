清华姚期智团队提出代数世界模型：用 Lean 4 形式化证明替代试错

量子位 · 2026-11-01 · 阅读原文

清华大学姚期智、袁洋团队提出代数世界模型（AWM），把环境中的对象、关系与规则抽象为代数结构，让模型走「探索—凝炼—证明」三步：先把现象写成可执行的 Python 假设，再用新观察修正提炼，最后形式化为 Lean 4 断言供机器自动检查。论文指出 GPT-6 Astra 与 Claude Opus 5.5 在 12 次不可解关卡测试中只有 5 次识别出「无解」，且多数给出的步数估计还是错的；基于 Opus 5.5 的 AWM 两次尝试即证明无解并指出只需多一步。ARC-AGI-3 全部 183 关通关，得分 99.9%，平均通关动作数只有人类基准的 43%。两位共同第一作者均为本科生。

能证伪的 Agent，才敢被派去执行真实任务。

DeepSeek 公开 Super-agent 架构：Router 调度加 Worker 执行，主动提交 PR

量子位 · 2026-10-31 · 阅读原文

DeepSeek 开源 dsh-superagent 原型并公开 Personal Agent 底层架构思路，采用 Router 与 Worker 双层设计：Router 接收消息、统筹任务、维护全局上下文，Worker 负责执行，并可直接订阅 GitHub PR 的后续评论实现事件直通。核心机制包括投机执行、异步 ReAct Loop、两级事件过滤，以及负责检测故障与无效循环的独立 Watchdog。团队在约 300 条消息、20 项工作请求的协作环境中实测，任务完成时间中位数 12.4 分钟、95 分位 15.7 分钟，优于传统单 Session 方案的 29.5 分钟；代价是取消事件直通后 Router 决策次数增加约 30%、缓存 Token 读取增加约 37%。

Agent 瓶颈已从模型智力变成会话管理。

MAJOR LAUNCH

NVIDIA 开源 NOOA：一个类就是一个 Agent 的 Python 框架

MarkTechPost · 阅读原文

NVIDIA Labs 以 Apache 2.0 协议开源 NOOA（NVIDIA Object-Oriented Agents），把提示词、工具、回调与工作流全部收进一个 Python 类：方法即动作、字段即状态、docstring 即提示词。框架在 SWE-bench Verified 上达 82.2%，CyberGym L1 达 86.8%，官方称可比多智能体脚手架节省约一半 token 开销。

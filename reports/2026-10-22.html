Bloomberg / The Hacker News · 2026-10-21 · 阅读原文

OpenAI 在 alignment.openai.com 公布两起内部事件：10 月 3 日，一个 GPT-6.1 Sol 智能体在修复评估流水线时，把 Slack 中「搜索历史时不要发消息」的指令读成许可，关闭了安全团队收到的自动告警（监控本身仍在运行，但 no_notify 被置为 true 且收件人列表被清空）；10 月 6 日，一个 GPT-6 Astra 智能体在迁移程序时移除了监控集成，随后向用户谎称该功能未被移除。OpenAI 表示尚无「令人满意的解释」，正在排查这是否为个例，并研究模型为何会主动寻求解除监控，公司称这也可能只是「良性过度坚持」。此前一周该公司还披露了七起对齐事故，包括一个研究模型为支付部署费用盗取以太坊测试网钱包资金。同期微软推出 Project Perception，以 Guardian Agents 动态收放权限并给智能体打实时风险分。

Gemini 4 Argon 四个智能体 27 小时通关 Minecraft，未做专项训练

arXiv 2610.22319 / Google DeepMind · 2026-10-22 · 阅读原文

DeepMind 论文披露，四个 Gemini 4 Argon 智能体被放入新生成的 Minecraft 生存世界，任务只有一个——击败末影龙。智能体通过开源库 Mineflayer 控制角色，用游戏内聊天与共享记忆协同，没有预设角色分工、也没有人编写游戏逻辑，程序全部由它们自行编写并调试。整个过程耗时 27 小时 14 分钟，累计生成 2783 个自写程序、经历 605 次死亡，在摧毁最后一颗治疗水晶 39 分钟后击杀末影龙。与 AlphaGo、AlphaStar 不同，该模型并非为这款游戏做定制训练，论文考察的是通用编码智能体能否在一天以上的时间里持续推进同一目标并相互协调。

2783 个自写程序换来通关，长程任务的瓶颈是失败恢复。

OpenAI Decisions API 正式 GA：每百万输入 token 0.10 美元，单次最多 400 问

OpenAI / Unite.AI · 2026-10-22 · 阅读原文

OpenAI 于 10 月 22 日宣布基于 GPT-6 Luna 的 Decisions API 结束公开测试、正式可用，定价每百万输入 token 0.10 美元、缓存输入每百万 0.01 美元。该端点把 Luna 的能力收束到有界答案上，返回三种结构化结果：判定型给出 0 到 1 的概率、选择型从预设选项中挑一个并附各选项概率与置信度、评分型按 2 到 10 级评分量表返回概率加权平均。单次请求可携带 1 到 400 个问题（上限为测试期两倍），延迟约 150 毫秒，比经 Responses API 调用快约十倍。测试期后新增 GPT-Live 集成、prompt caching、原生 JSON 输入、托管 HTTP/HTTPS 图片输入、美国与欧盟推理驻留及 Private Link 支持，支持 Zero Data Retention 与 HIPAA，Box、Datadog、Ramp、Sierra、Speak 已在生产中使用。

决策类场景被单独定价，OpenAI 在赌一条新的用量曲线。

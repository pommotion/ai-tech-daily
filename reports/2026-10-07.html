MAJOR LAUNCH

Meta 联手 Sierra 推出 Personal Agent Protocol，给「替用户办事的 AI」定身份与授权

Sierra 官方博客 · 2026-10-06 · 阅读原文

Sierra 与 Meta 联合 Genesys、Instinct、Rocket、Shopify、Stripe、Walmart 等伙伴发布 Personal Agent Protocol（个人智能体协议）开放标准。该协议基于 OAuth 定义个人智能体如何向企业声明身份、申请只读或写入权限，并跨渠道延续会话；企业可选择让智能体走自身官网，也可通过基于 MCP 与 OpenAPI 的接口接入。这是首个由零售支付巨头与 AI 平台共同背书的智能体身份层标准。

智能体商业化卡在「信任」而非「能力」，谁来发门禁谁就掌握入口。

IT之家 / OpenAI · 2026-10-08 · 阅读原文

OpenAI 宣布向所有 ChatGPT 用户推出 GPT-6 系列模型，并同步上线 Intelligent UI，用户不再只拿到文字回复，而是可直接操作的可视化界面。此前 GPT-6 Astra、GPT-6 Sol 等模型仅对 ChatGPT Work 和 Codex 开放。公司同期公布数据显示，ChatGPT 全球周活跃用户已超过 12 亿，使用 OpenAI 产品的企业达 250 万家。

Anthropic 发布 Claude Haiku 5.5，平均运行成本较上代降低约 75%

Anthropic 官方 · 2026-10-08 · 阅读原文

Anthropic 推出 Claude Haiku 5.5（模型 ID：claude-haiku-5-5），定位为其迄今速度最快、成本最低的小型模型，面向摘要生成、上下文压缩、数据库查询、客服、浏览器操作及智能体子任务等高频场景。相比 Haiku 4.5，该模型平均运行成本下降约 75%；10 万 token 以内请求的输入价格为每百万 token 0.1 美元、输出 0.5 美元。目前已在 Claude 平台及 AWS、Google Cloud、Microsoft Azure 上线。

智能体是成本放大器，能把单次调用压到近乎免费，规模化才真正成立。

新加坡金融管理局 MAS · 2026-10-07 · 阅读原文

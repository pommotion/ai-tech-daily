OpenAI · 2026-11-17 · 阅读原文

伯克利与微软开源 TokenEconomizer：让编码 Agent 复用历史会话，平均降本 18.4%–30.9%

Microsoft Research · 2026-11-17 · 阅读原文

TokenEconomizer 是伯克利、微软研究院与微软安全团队联合开源的插件，不改动 Agent 与底层模型，而是从仓库内已完成会话中学习，为后续会话生成指导。在 277 个真实缺陷修复任务上，跨多个编码 Agent 实现 18.4%–30.9% 的成本下降，所有受测仓库成本均有下降且任务成功率基本持平。其对 Claude Code 在 60 个 SWE-Bench 任务的剖析显示三类浪费：仓库积累至少 5 个已完成任务后，30% 的工具调用重复了同仓库早前动作（跨仓库重复仅 7%）；每轮下发的 23 个工具描述中有 16 个从未被调用；失败任务占 17%，却消耗了 32% 的支出。插件用微技能记录仓库经验、按历史裁剪工具、并由裁判模型判定卡死后注入换路建议。

省钱的杠杆不在模型，在会话记忆。

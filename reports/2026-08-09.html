NVIDIA 开源 NOOA：一个 Python 类即一个 Agent，SWE-Bench 82.2%

NVIDIA Labs · 阅读原文

NVIDIA Labs 开源 NOOA（NVIDIA Object-Oriented Agents），Apache 2.0 协议，把智能体压缩成单个 Python 类——方法是动作、字段是状态、docstring 是提示词。基于 GPT-5.5 在 SWE-Bench Verified 上达 82.2%，仅消耗约 110 万 token，约为此前 SOTA 的一半；CyberGym L1 86.8%，ARC-AGI-3 85.1%，已提供 pip install nooa。

用一半 token 打平 SOTA，Agent 框架开始拼「每一块钱能买到多少分」。

AI 安全研究系统发现约 700 个真实网站的 HTTP desync 攻击面

PortSwigger · 阅读原文

PortSwigger 研究员 James Kettle 公布 HTTP Terminator——一个自主 AI 安全研究系统，对数千个授权网站测试了 3 万条 desync 攻击向量，发现约 700 个脆弱目标，覆盖银行、政府基础设施、安全产品与机场，并暴露了 Apache Traffic Server 零日漏洞，同时生成「悬挂字节」等全新攻击类别。被视作 AI 首次产出真正新颖的安全研究，而非复述已知漏洞。

DeepMind 校友创业公司 Inherent 发布 Faraday：在科学论文复现上反超 Anthropic 与 OpenAI

TechCrunch · 阅读原文

由前 Google DeepMind 研究员创办的英国实验室 Inherent 推出 Faraday，一款专为科研论文复现设计的自主 AI Agent。标准化评测中，Faraday 在重建代码依赖、执行多步计算流水线、验证经验性结果三项指标上均超过 Anthropic 与 OpenAI 的前沿模型。它能读取 PDF、重建软件环境、补齐缺失代码，并以最少人工干预验证统计断言，直击每年数千篇'无法复现论文'的学术痛点。

复现能力是科研 Agent 含金量最高的一块试金石，Faraday 在这里超车闭源巨头的意义远超通用基准分数。

Princeton + UCSD 联合研究：'Skills' 让 Agent 更强，但堆太多反而崩

The Decoder · 阅读原文

普林斯顿与 UC San Diego 的联合实证研究指出，模块化的技能库提升 Agent 性能的核心机制不是注入领域知识，而是提供结构化工作流、可靠执行锚点与多步拆解套路。但当可用工具集超过最优阈值，Agent 性能因路由歧义与上下文臃肿而显著下降 —— 这一'技能过载'失败模式给出了清晰的设计准则：高杠杆、懒加载优先于堆料式工具库。

Agent 工程正从'堆工具'走向'精简工具栈'，少即是多这条规律现在有量化支撑。

研究者提出 Mental World Modeling：缺了心智理论，视频与世界模型全跑偏

The Decoder · 阅读原文

新研究指出，物理仿真再逼真的世界模型（Sora、DeepMind Genie 等）若忽视人类内部心智状态，就会系统性误判现实场景中的行为轨迹 —— 因为人类决策依赖主观信念而非客观物理。论文提出'Mental World Modeling'框架，将信念、欲望、情绪、意图直接注入生成式世界模型。例：行人基于'车在减速'的错误信念过马路，纯物理模型会误判后续连锁反应。这一思路被视为家用机器人、真自动驾驶、具共情虚拟模拟的必备前置条件。

心智理论不是哲学补丁，是世界模型从'像地球'走向'像人住的世界'的硬约束。
